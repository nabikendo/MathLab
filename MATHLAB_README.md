# MathLab Expressive

Protótipo independente de aprendizagem de Matemática com interface responsiva marrom e verde-limão.

## Uso
Abra `index.html` no navegador. Contém 12 questões demonstrativas, treino, diagnóstico de oito itens, cinco trilhas e progresso armazenado localmente.

## Limitações
Ainda não contém o currículo integral, questões oficiais do ENEM, autenticação, IA, PDFs ou diagnóstico adaptativo validado.

## Publicação
O workflow em `.github/workflows/pages.yml` publica a página estática após a configuração de GitHub Pages com origem **GitHub Actions** nas configurações do repositório.
